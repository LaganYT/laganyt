# Impact

Apps that share the "Impact" prefix.

| Repo | What it does |
| --- | --- |
| [ImpactStream](https://github.com/LaganYT/ImpactStream) | Streaming frontend across web, iOS, Android, and Roku from one codebase. |
| [ImpactScribe](https://github.com/LaganYT/ImpactScribe) | Audio transcription with Whisper in the browser. No upload, no server. |
| [ImpactTube](https://github.com/LaganYT/ImpactTube) | YouTube frontend without the tracking cookies. |
| [ImpactConnect](https://github.com/LaganYT/ImpactConnect) | Real-time chat with direct messages and invite-only rooms, on Supabase. |
| [ImpactTTS](https://github.com/LaganYT/ImpactTTS) | Text to speech with Edge voices, adjustable rate and pitch, MP3 download. |
