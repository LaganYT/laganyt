# Fuzzy

Everything around [Fuzzy Macro](https://github.com/Fuzzy-Team/Fuzzy-Macro), an
open-source Bee Swarm Simulator macro in Python.

| Repo | What it does |
| --- | --- |
| [Fuzzy-Macro](https://github.com/Fuzzy-Team/Fuzzy-Macro) | The macro itself: Python automation, task systems, and a web GUI. |
| [Fuzzy-Pattern-Maker](https://github.com/Fuzzy-Team/Fuzzy-Pattern-Maker) | Tool for testing and developing patterns and paths for the macro. |
| [Fuzzy-Macro-Interactive-Demo](https://github.com/Fuzzy-Team/Fuzzy-Macro-Interactive-Demo) | A preview of the GUI in the browser. |
| [Fuzzy-Macro-Docs](https://github.com/Fuzzy-Team/Fuzzy-Macro-Docs) | Documentation. |
| [macro-auto-install](https://github.com/Fuzzy-Team/macro-auto-install) | One-line command that walks you through installing the macro. |
| [Fuzzy-Macro-Wheels](https://github.com/Fuzzy-Team/Fuzzy-Macro-Wheels) | Prebuilt Python wheels for Intel Macs below macOS 10.15. |
| [virtual-monitor-helper](https://github.com/Fuzzy-Team/virtual-monitor-helper) | — |
| [fuzzymacroaimodels](https://github.com/Fuzzy-Team/fuzzymacroaimodels) | — |
