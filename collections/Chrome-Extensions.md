# Chrome Extensions

Sidebars and study helpers that put a tool next to the page you're already on.

| Extension | What it does |
| --- | --- |
| [mathway-sidebar](https://github.com/LaganYT/mathway-sidebar) | Mathway in a browser sidebar, for working through a problem without leaving the page. |
| [QuixAnswer](https://github.com/LaganYT/QuixAnswer) | AI chat extension backed by Groq. |
| [perplexity-sidebar](https://github.com/LaganYT/perplexity-sidebar) | Perplexity in a browser sidebar. |
| [GPT-Sidebar](https://github.com/LaganYT/GPT-Sidebar) | ChatGPT in a browser sidebar. |
| [InterALEKS](https://github.com/LaganYT/InterALEKS) | Adds a few features to McGraw Hill's ALEKS. |
